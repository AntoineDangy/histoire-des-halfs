  15. 2021 Abandon de courseMise en venteRefit, modification

    June "ebay kleinanzeigen", for Sale Mini Transat 650 Prototyp 232 keine Pogo, 24.950 €, Cuxhaven, Baujahr 1999, Grosses Refit 2013. Neuer Carbon Mast 2017 (komplettes Rick, Rechnung vorhanden für Euro 16000), 2 D Kantingkiel für Backbord und Steuerboard sowie der Winkel der Finne können eingestellt werden, Gezeichnet von Lucas/Raison. Boot ist bei 3 Mini Transat Regatten gestartet (1999-DNF, 2001 – 7th, 2007 – 19th). 2007 bis 2013 ist das Boot nicht bewegt worden. 2017 ist das komplette laufende gut erneuert worden. Dann ist das Boot an einen privaten Eigner in Deutschland verkauft worden. Das Boot besitzt zwei Ballastwassertanks a 150 l. Leinen für den Kiel sind in 2014 durch Dynema ersetzt worden. Deckhardware (Blöcke, Klemmen, etc) zu 95% von Harken, 4x selbstholende inchen von Harken, Spinlock Fallenstopper, Pinnenausleger ebenfalls von Spinlock. Für die Code Zeros ist ein Fuler (Rollanlage) von NEX vorhanden. Das Boot steht im Winter seit 2014 durchgehen in einer Halle. Die Energie Versorgung erfolgt durch eine Vertus Batterie die über ein Solarpanel (max. 60 W) geladen wird. Alternative ist aus ein 220 V Ladegerät vorhanden. Das Solar Ladegerät ist von Vingtor. Das Bordnetz (ohne Autopilot) verbraucht ca. 20 W. Das Boot ist in einem guten bis sehr guten Zustand und kann nach Absprache besichtigt werden.
