2014 Janvier, 2005 plywood/epoxy professionally built by Randle Yachts, Cape Town. Sailed back to UK via St Helena, Azores and France. Raced in 2008 qualification season. Fixed keel, 200lts water ballast each side. Aluminiumn spars. Main/Jib/Storm jib, tri sail. 2 x kites. Safety kit inc Epirb, Liferaft, danbouy etc. All Raymarine ST60, S1G instrumentation (less autopilot ram). GPS, VHF. All refit tools inc. Craddle inc. Everything you need to get you going (less AIS). Sailed recently. Now sat in Plymouth Yachtquay Haven awaiting her next adventures.... Search 'Thunder Piers Dudin' on flickr for photos.
